# Checkpoint 07 — Biblioteca versionada

Os prompts dos checkpoints 01–06 estão organizados por objetivo em `devops/<slug>/`.
Cada pasta mantém o `prompt.md`, a documentação humana e o config Promptfoo juntos;
os prompts usam frontmatter, variáveis parametrizadas e versão SemVer.

As etapas da migração do Forge permanecem em três prompts próprios para preservar a sequência
diagnóstico → planejamento → execução. Não foram copiados arquivos do repositório de referência;
esta organização mantém o conteúdo original deste projeto.
